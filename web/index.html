采集完整调查数据

Node 场景文件导出 setup、exercise、cleanup 函数。在仓库目录运行：

node bin/moonheap.mjs capture --scenario examples/cache-scenario.mjs --output-dir work/my-capture --allocation-traces

将生成的 before、growth、cleanup 三份快照依次放入 A、B、C。采集会暂停目标进程；请在可控环境中运行你的测试场景。

Chrome 用户可在 Memory 面板采集堆快照。只有开启分配跟踪后采集的快照才可能包含分配调用栈。
