# 完整调查流程补齐计划

v0.1 已实现基本快照分析，但仍缺少大文件逐块解析、分配来源、
多条引用路径、循环组、保留体积变化、清理后存活筛选、完整报告与通用采集。
这一轮按实际调查流程补齐，每一项必须同时有库接口、适用的 CLI/网页入口和验证。

- [x] 逐块导入：数字数组直接读取、跨块字符串/数值、进度、可配置输入预算。
- [x] 来源信息：对象位置、分配函数和分配调用栈，缺失时明确显示。
- [x] 深入引用：多条根路径、循环引用组、支配树导航和体积图。
- [x] 比较：保留体积变化、独立分页、类型/状态/增量过滤。
- [x] 三阶段调查：基线、增长、清理；筛选新增后仍存活的对象并列出证据。
- [x] 完整导出：全部匹配结果的 JSON、CSV、自包含 HTML，明确上限且不静默截断。
- [x] 通用 Node 场景采集：自定义 setup/exercise/cleanup、分配跟踪、来源记录。
- [x] 完整网页：三快照、调查视图、历史导航、保存/恢复工作区、进度和错误恢复。
- [x] 综合验收：真实保留/清理场景、大文件、CLI、浏览器、跨后端；文档与新版本发布。

“完整”按上述闭环验收，不以占位按钮、固定演示数据或单独底层函数算完成。
对 V8 没有提供的信息，不伪造值；对于有预算的搜索，明确说明搜索是否穷尽。
